# MontNoir Runner — downloads

This repository distributes MontNoir Runner binaries and installers. The application source repository remains private. Source archives generated by GitHub for this repository contain distribution documentation only.

## Linux and macOS

Download the installer from the latest published release, then run it:

```sh
curl --proto '=https' --proto-redir '=https' --tlsv1.2 -fL \
  https://github.com/mn1337/montnoir-releases/releases/latest/download/install.sh \
  -o montnoir-install.sh
bash montnoir-install.sh user
montnoir login
montnoir status --json
```

The installer selects AMD64 or ARM64, checks the archive against its embedded SHA-256, and installs the application and Docker backend. Enter the connect code from MontNoir when `login` requests it. `online` / `ready` confirms the connection. Use the same OS account for installation and subsequent commands.

Linux cloud fleet installations use `bash montnoir-install.sh public`, followed by `montnoir-fleet login --credential-file /path/to/issued-credential.json`.

## Windows

Run in PowerShell:

```powershell
Invoke-WebRequest -UseBasicParsing https://github.com/mn1337/montnoir-releases/releases/latest/download/install.ps1 -OutFile montnoir-install.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\montnoir-install.ps1
montnoir login
montnoir status --json
```

Windows setup may require elevation, a WSL/Docker Desktop first launch, and a reboot. Repeat the installer after completing the requested system step. Windows ARM64 binaries are cross-built; refer to the release notes for native platform validation.

## Resources and operation

For one small workload, allow approximately 4 vCPU, 4 GiB RAM and 64 GiB disk for the Linux backend. Heavy analyzers require more memory. The normal private session disk reserves 32 GiB; `--compact` / `-Compact` uses 28 GiB and smaller session limits. These are part of the total host disk requirement. Existing settings and sessions are preserved.

```sh
montnoir start
montnoir stop
montnoir logs --follow
montnoir doctor
```

Releases include six platform archives, `release.json`, checksums, and a Sigstore signature bundle. Each archive includes the licenses and notices of its linked Go dependencies. The HTTPS bootstrap binds a particular version and its archive hashes; this is not a replacement for independent signature verification. The source workflow identity and verification procedure are included in `docs/RELEASING.md` in each archive.
